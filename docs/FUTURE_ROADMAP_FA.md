# امکانات پیشنهادی نسخه‌های بعد Repo Time

این فهرست دقیقاً چیزهایی را مشخص می‌کند که برای تبدیل MVP فعلی به محصول تجاری کامل باید اضافه شوند.

## اولویت خیلی بالا — اتصال‌های واقعی

1. **درگاه پیامک واقعی**
   - API Provider، Sender Number، Template و Webhook تحویل
   - صف Retry، گزارش خطا و لغو ارسال
   - رعایت لیست سیاه مخابرات و رضایت مخاطب

2. **احراز هویت عمومی و نقش‌ها**
   - ثبت‌نام/ورود مدیر کسب‌وکار
   - نقش مدیر، پذیرش، پرسنل و حسابدار
   - سطح دسترسی جدا برای تقویم، مشتری و گزارش

3. **رزرو آنلاین عمومی**
   - لینک مستقل هر کسب‌وکار
   - نمایش زمان خالی واقعی
   - جلوگیری از رزرو هم‌زمان و ظرفیت هر خدمت
   - تأیید، لغو و جابه‌جایی توسط مشتری

4. **تقویم شمسی واقعی**
   - تبدیل میلادی/شمسی در Backend
   - تعطیلات رسمی، شیفت پرسنل و منطقه زمانی
   - تکرار هفتگی و Block کردن زمان‌های غیرقابل رزرو

## اولویت بالا — مدیریت کسب‌وکار

- مدیریت چند شعبه و چند تقویم
- پورسانت پرسنل و تسویه ماهانه
- کالا/خدمت ترکیبی و موجودی
- بیعانه و پرداخت اینترنتی
- فاکتور PDF و خروجی Excel
- پرونده فایل‌دار با عکس، سند و رضایت‌نامه
- Import استاندارد Excel با پیش‌نمایش و حذف تکراری‌ها
- Log تغییرات برای مشخص شدن ویرایش هر کاربر
- Backup زمان‌بندی‌شده و بازیابی نسخه‌ها

## اولویت متوسط — رشد و ارتباط با مشتری

- پیام‌رسان بله، واتساپ و Telegram Provider
- کمپین Segment شده بر اساس مراجعه، مبلغ و رفتار
- امتیاز، Level و کیف پول باشگاه مشتریان
- کد تخفیف، کارت هدیه و Referral
- نظرسنجی لینک‌دار و NPS
- تولد هوشمند با Coupon خودکار
- گزارش نرخ بازگشت و ارزش طول عمر مشتری

## اولویت متوسط — کیفیت محصول

- PWA و نصب روی موبایل
- Push Notification و اعلان مرورگر
- Dark Mode اختیاری
- تست‌های Component و End-to-End
- Audit امنیت، Rate Limit و CAPTCHA فرم عمومی
- مشاهده‌پذیری با Sentry/Log و Alert
- زبان دوم انگلیسی/عربی

## چیزهایی که اکنون کم است

- پیام در دیتابیس صف می‌شود ولی به اپراتور مخابراتی ارسال نمی‌شود.
- رزرو آنلاین صفحه عملیاتی عمومی و پرداخت ندارد.
- نمودارها داده‌ی خلاصه را نشان می‌دهند اما Export و Drill-down ندارند.
- نقش پرسنل در UI دیده می‌شود اما مجوز سروری جدا هنوز اضافه نشده است.
- Import مشتری، دامنه اختصاصی و شماره اختصاصی نیازمند سرویس بیرونی هستند.

## پیشنهاد ترتیب نسخه‌ها

- `v1.1`: ورود عمومی، نقش‌ها، تقویم شمسی و رزرو واقعی
- `v1.2`: Provider پیامک، Reminder Worker و گزارش تحویل
- `v1.3`: پرداخت، بیعانه، فاکتور و پورسانت
- `v1.4`: باشگاه مشتریان و اتوماسیون بازگشت
- `v2.0`: چند شعبه، اپ PWA و Marketplace اتصال‌ها
